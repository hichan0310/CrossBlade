# 전투 행동 그래프와 모션 편집

## 몸 피격 판정 편집

Move 노드를 선택하고 오른쪽 미리보기 위의 **몸 피격 판정** 탭을 누릅니다. 몸 판정이 없는 Move는 아래 **몸 피격 박스 만들기**로 생성합니다. 기존 `bodyCollider`가 있으면 그 콜라이더를 편집합니다.

미리보기에서 몸 박스 내부를 드래그하면 중심이 이동하고, 모서리 노란 점을 드래그하면 크기가 바뀝니다. 아래 **몸 중심 (로컬) / 몸 크기**에 수치를 직접 입력할 수도 있습니다. 좌우 방향과 X/Y 이동이 표시 위치에 반영됩니다. **Move 저장**으로 프리팹에 반영합니다. 몸 박스는 무기 공격 판정에 등록되지 않으며 실제 전투의 `bodyCollider`로 사용됩니다.

몸 박스는 해당 Move 전체에 적용되는 고정 판정입니다. 프레임별 형태 변화나 무적 구간 설정은 포함하지 않습니다. 이 창의 직접 조작은 BoxCollider2D를 지원하며, 기존 다른 콜라이더 형태는 **몸 콜라이더 Inspector 열기**로 편집합니다.

## 공통 방어·피격

오른쪽 상단 **이 그래프의 공통 방어 · 피격**에서 **공통 방어 / 공통 피격** 드롭다운으로 선택합니다. 목록에는 현재 그래프에 포함된 Move만 이름과 경로로 표시됩니다. 후보가 없다면 먼저 해당 Move를 그래프에 추가하세요. 저장하지 않은 그래프는 먼저 저장 위치를 고릅니다.

- 개별 방어·피격 연결이 있으면 해당 Move를 사용합니다.
- 개별 연결이 없으면 공통 설정을 사용합니다. 공통 설정도 없으면 분기 대상은 없습니다.
- 공통 연결선은 그리지 않고 노드 포트에 공통 대상 이름을 표시합니다. 미리보기와 실제 전투 모두 같은 우선순위를 사용합니다.
- **공통값과 같은 개별 연결 정리**는 공통 대상과 일치하는 연결만 지웁니다. 다른 대상을 가리키는 예외 연결은 유지합니다. Undo로 되돌릴 수 있습니다.

공통 설정은 그래프 `.asset` 자체에 저장됩니다. Move 프리팹에는 공통 설정을 기록하지 않으므로 같은 Move를 여러 그래프에서 공유해도 공통값은 서로 독립적입니다. 예전 `_Reactions.asset` 값은 그래프 로드 시 가져옵니다. 그래프 밖의 대상은 공통 분기에 사용하지 않습니다.

실제 전투에서는 캐릭터의 **Actor > Combat Move Graph**에 사용할 그래프 `.asset`을 지정하세요. 공통값은 해당 Actor의 그래프에서 가져옵니다. 미리보기는 현재 열린 그래프를 사용합니다. Actor에 그래프가 없으면 기존 개별 연결만 사용합니다.

## 애니메이션으로 새 Move 생성

그래프 상단 **애니메이션 → Move**에서 원본 클립을 추가하고 시작·끝 프레임과 속도를 편집하세요. **Move 만들기 · 전투 그래프에 추가**를 누르면 `.anim`과 Move 프리팹을 함께 저장하고 새 노드를 선택합니다. 기존 편집 `.asset`을 더블클릭해서 같은 버튼을 사용할 수도 있습니다. 시퀀스 그래프를 따로 만들 필요가 없습니다.

그래프 캔버스는 Unity UI Toolkit의 **GraphView**로 구현합니다. 확대·이동·노드 선택·드래그·연결선 처리는 GraphView의 기본 기능을 사용하며, 직접 GUI 좌표를 확대하는 이전 캔버스는 제거했습니다. 검색 목록과 그래프, 오른쪽 미리보기는 독립된 영역입니다. 그래프와 편집 패널 사이 경계선을 드래그해 너비를 조절할 수 있습니다.

Graph Toolkit 패키지와 GraphView는 별개입니다. 이번 구현은 기존 `.asset`과 Move 참조를 유지하는 내장 GraphView를 사용합니다. [Unity GraphView API](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Experimental.GraphView.GraphView.html), [Graph Toolkit 설치 문서](https://docs.unity3d.com/Packages/com.unity.graphtoolkit@0.4/manual/installation.html).

**CrossBlade > Combat Move Graph**를 엽니다. 왼쪽에서 실제 Move 프리팹의 연결을 편집하고, 오른쪽 **모션 · 이동 · 히트박스** 탭에서 선택한 행동을 보면서 편집합니다. 별도 시퀀스나 재생 목록을 만들 필요가 없습니다.

## 그래프 전체 저장과 모든 행동 보기

기존에 만든 7개의 `NewMove` 프리팹을 묶은 **`Assets/UserCombatGraph.asset`**을 Project에서 더블클릭하세요. 연결되지 않은 행동까지 모두 들어 있습니다. 각 Move의 애니메이션·이동·히트박스·연결은 기존 프리팹을 참조하며 복제하지 않습니다.

- **저장**: 시작 Move, 전체 노드 목록, 노드 배치, 화면 확대/이동 상태와 미리보기 캐릭터·배속·카메라·준비 지연 설정을 `.asset`에 저장합니다. 처음 저장할 때 파일 위치를 선택합니다.
- **같은 폴더 추가**: 시작 Move와 같은 폴더에 있는 Move 프리팹을 연결 여부와 관계없이 추가합니다. 하위 폴더는 포함하지 않으며, 다른 폴더의 프리팹은 드래그해 추가할 수 있습니다. 이미 들어 있는 항목은 중복 추가하지 않습니다.
- **검색 입력 / 전체 노드 검색 목록**: 포함된 노드를 목록에서 찾습니다. 항목을 누르면 해당 노드를 선택하고 화면을 그 위치로 이동합니다.
- **전체 보기**: 모든 노드가 보이도록 화면을 맞춥니다. **자동 배치**는 노드를 격자로 재배치합니다.
- **마우스 휠**: 그래프를 확대·축소합니다. 중간 마우스로 화면을 이동합니다.

시작 Move를 바꾸거나 **연결 다시 읽기**를 눌러도 기존 노드들은 제거되지 않습니다. 저장한 그래프는 더블클릭하거나 상단 **그래프 파일**에 지정해 다시 엽니다. 같은 Move를 다른 그래프에서도 참조하면 Move 편집은 공유됩니다.

## 행동 만들고 연결하기

1. **빈 Move 만들기**를 누르고 새 프리팹 이름과 저장 위치를 지정합니다. 생성한 Move가 그래프 노드로 추가됩니다. Project의 **Create > CrossBlade > Empty Move**에서도 만들 수 있습니다.
2. 노드를 선택합니다. 오른쪽 **애니메이션 · 캐릭터 설정**에서 Composer로 구운 `.anim`을 지정합니다. 공격이면 Category를 Attack으로 설정하고 실행 시간과 데미지도 지정합니다.
3. 다른 Move 프리팹을 그래프에 드래그해 추가합니다.
4. 출발 노드의 **다음 행동 / 방어 / 피격** 출력 포트에서 대상 노드의 **이전 행동** 입력 포트로 드래그해 연결합니다.
5. **저장**을 누릅니다. 연결은 실제 Move 프리팹에 저장됩니다.

파란 선은 다음 행동 후보(`after`), 초록 선은 방어(`guardMove`), 빨간 선은 피격(`hitMove`)입니다. 다음 후보는 여러 개, 방어·피격 대상은 각각 하나입니다. 연결선을 클릭해 선택하고 **Delete**로 삭제할 수 있습니다. **Ctrl+Z**로 복구합니다. **전투 분기 설정** 탭에서도 후보 순서와 연결을 편집할 수 있습니다. 노드 제목을 드래그해 배치하고 중간 마우스 버튼으로 화면을 이동합니다. 노드 목록과 배치·확대/이동 상태는 그래프 파일에 저장됩니다.

## 그래프 연결을 따라 모션 보기

- 노드를 선택하면 오른쪽에 해당 행동의 미리보기와 편집 도구가 표시됩니다.
- **연결된 다음 행동 이어 재생**을 켜고 **재생**을 누릅니다. 다음 후보가 하나면 끝에서 해당 행동으로 넘어갑니다. 여러 개면 끝에서 멈추고 선택을 기다립니다. 후보가 없으면 끝에서 정지합니다.
- **다음 → 행동 이름**을 누르면 현재 행동의 이동 끝 위치에서 해당 행동을 이어 봅니다.
- **현재 시점에서 방어 / 피격 → 행동 이름**은 현재 프레임의 이동 위치에서 해당 분기를 이어 봅니다.
- 재생 중인 행동은 그래프에서도 선택 표시가 바뀝니다. 다른 노드를 직접 선택하면 그 행동의 처음과 원점으로 돌아갑니다.
- **선택 노드 처음부터 · 위치 초기화**로 누적 위치를 초기화할 수 있습니다.

이것은 실제 그래프 연결을 이용한 검토 재생입니다. 게임의 다음 후보는 여전히 플레이어·AI의 선택 대상이며, 미리보기의 이어 재생이 게임의 자동 실행 규칙을 바꾸지는 않습니다. 분기 버튼도 충돌을 일으키거나 전투 이벤트를 실행하지 않습니다.

## 느리게 보기와 이전 행동부터 이어 보기

**미리보기 속도**를 0.05~2배로 조절하거나 **0.1× / 0.25× / 0.5× / 1×** 버튼을 누르세요. 이 값은 미리보기 시계에만 적용되며 클립과 Move 실행 시간은 바꾸지 않습니다. 프레임 이동은 배속과 관계없이 한 프레임씩 이동합니다.

1. 그래프에서 연결을 확인하고 싶은 **뒤쪽 행동**을 선택합니다.
2. **이 노드로 연결된 이전 행동 찾기**를 누릅니다. 프로젝트의 Move 프리팹 중 현재 행동을 `after`(다음 행동 후보)로 참조한 항목을 찾습니다. 현재 캔버스에 없는 이전 행동도 검색합니다.
3. **이전 행동** 목록에서 원하는 것을 고르고 **선택한 이전 행동 → 현재 행동 재생**을 누릅니다.
4. 이전 행동부터 선택한 현재 행동까지 이동 위치를 누적해 재생한 뒤 정지합니다. 이전 행동에 다른 다음 후보가 있어도 지정한 연결을 선택하며, 현재 행동의 뒤쪽 노드로는 넘어가지 않습니다.
5. **이 두 동작 다시 재생**으로 원점부터 반복 검토할 수 있습니다. 배속은 두 동작에 동일하게 적용됩니다.

이 기능은 그래프 연결을 바꾸거나 별도 시퀀스를 만들지 않습니다. 현재는 일반 다음 후보 연결을 대상으로 하며, 방어·피격 연결은 기존의 현재 시점 분기 버튼으로 검토합니다.

## X/Y 이동 편집

1. 원하는 그래프 노드를 선택하고 타임라인으로 자세를 찾습니다.
2. 화면 아래 **이 Move에 X/Y 곡선 이동 사용**을 누릅니다. 이 Move의 이동 방식이 CurveXY, 적용 구간이 StartupAndActive로 바뀝니다.
3. X/Y 곡선을 클릭해 편집하거나, **현재 시점에 넣을 위치**를 입력하고 **현재 시점에 X/Y 위치 키 저장**을 누릅니다.
4. **이동 경로 편집**을 켜면 하늘색 현재 위치 점을 드래그해 해당 시점의 키를 넣을 수 있습니다.
5. **Move 저장**을 누릅니다.

곡선 가로축은 적용 구간의 진행률 0~1, 세로축은 Unity 이동 거리입니다. X+는 행동 시작 시 전방, Y+는 위쪽입니다. 각 Move의 시작점은 상대 위치 (0, 0)입니다. 왼쪽 방향에서는 X만 반전됩니다. 다음 행동으로 넘어가면 앞 행동의 이동 위치가 누적됩니다. 방어·피격 분기는 중단 시점의 위치를 사용합니다.

**미리보기 준비 지연**은 실제 Actor의 Move Start Delay와 맞춥니다(기본 0.1초). 모델 애니메이션은 준비 지연과 Move 실행 시간 전체에 걸쳐 재생됩니다. 기존 FixedDistanceForward와 FixedSpeedForward도 위치에 반영하지만, 상대 위치에 의존하는 StopAtRange와 PassThroughTarget은 경로를 예측하지 않습니다.

## 히트박스 편집

1. 모션을 재생하거나 **이전/다음 프레임**, **클립 시간**으로 공격 자세를 찾습니다.
2. **박스 추가**를 누릅니다. 박스 중앙을 끌어 이동하고 오른쪽 위 노란 손잡이로 크기를 조절합니다. 히트박스를 드래그할 때는 **이동 경로 편집**을 끕니다.
3. **판정 시작/종료 프레임**을 지정합니다. 양 끝 프레임을 포함합니다. 주황색은 현재 활성, 회색은 비활성 구간입니다.
4. 중심·크기·데미지 계수를 확인하고 **Move 저장**을 누릅니다.

현재 판정은 Move 기준 XY 평면의 2D Collider bounds 겹침입니다. 박스는 캐릭터 기준 고정 영역이며 검 본을 따라 움직이는 3D 콜라이더가 아닙니다. 이동하는 타격 영역은 서로 다른 구간의 박스를 여러 개 배치해 표현할 수 있습니다. 명중 후 비활성화된 박스를 시간 구간 검사로 다시 켜지는 않게 했습니다.

박스 추가·삭제는 프리팹에 즉시 저장됩니다. 위치·크기·구간과 곡선 편집에는 Undo를 사용할 수 있습니다. 판정 구간은 클립 전체에 대한 비율로 저장되므로 클립을 교체하면 구간을 다시 확인하세요.

## 캐릭터와 적용 범위

미리보기 기본 캐릭터는 엘든링 모델입니다. 클립과 같은 뼈대의 캐릭터를 지정해야 합니다. 실제 런타임 프리팹에 CharacterAnimationPlayer가 있으면 해당 방향·루트 고정 설정을 사용합니다. 기본 모델의 수평 고정 본은 `Model/skeleton/Pelvis`입니다. Y 이동 곡선은 실제 전투 위치를 바꾸며, 애니메이션 안의 몸 자세·높이 변화는 별도로 남습니다.

한 개의 미리보기 캐릭터와 카메라를 선택한 노드에 재사용합니다. 모델 간 자동 리타게팅, 노드 사이 자동 포즈 블렌드, 상대와의 충돌·넉백 시뮬레이션은 이 미리보기에서 수행하지 않습니다.

이전에 만든 MovePreviewSequence 파일은 보존되지만, 현재 그래프 편집에는 필요하지 않습니다. 시퀀스 설계용 **Motion Graph** 메뉴는 제거했습니다. 실제 전투 행동의 편집 진입점은 **Combat Move Graph**입니다.

## 그래프 입력 회귀 검증

`CombatMoveGraphInteractionValidation.Run`은 별도 테스트 프로젝트에서 그래픽 모드로 실행합니다(`-executeMethod`, `-quit` 없이 실행, 검사 종료 시 에디터 종료). 100개 임시 Move로 40%/150% 배율에서 노드 클릭 판정, 툴바 영역 분리, 실제 마우스 드래그, 좌표 저장, 연결 삭제·Undo를 검증합니다. 기존 사용자 그래프를 테스트 대상으로 수정하지 않습니다.
