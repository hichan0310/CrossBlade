# CrossBlade 엘든링 대량 모션 워크플로

모든 작업은 `/home/hichan/CrossBlade/gitrepo/CrossBlade` Unity 프로젝트 안에서 진행합니다. 별도 MotionViewer 프로젝트를 열 필요가 없습니다.

대량 선별 단계에서는 MotionViewer에서 사용하던 `ER_Base_Male.fbx`와 `ER_Base_Male_Animated.prefab`을 사용합니다. 임시 캡슐 마네킹은 사용하지 않습니다. 기존에 화면에 보이던 단근은 미리보기 카메라에 CombatScene이 함께 잡힌 문제였으며, 미리보기 전용 씬과 3D 렌더 경로로 수정했습니다.

## 모션을 직접 보면서 선별하기

Unity에서 **CrossBlade > Elden Ring Motion Library**를 엽니다.

**Category / 무기 타입**에서 직검·대검·도·창·도끼 등으로 모션을 묶어 볼 수 있습니다. 각 항목에는 모션 수가 표시됩니다. 무기 정보가 없는 항목은 **무기 미분류**에 모았습니다. **동작 종류**로 공격 유형을 추가로 좁힐 수 있으며, 무기 타입을 바꾸면 기존 검색어와 원본 그룹 필터는 초기화됩니다.

현재 색인된 고유 모션 16,512개를 이름, 그룹, 무기 종류와 동작 분류로 좁힐 수 있습니다. 실제 선별은 이름으로 판단하지 않습니다. 왼쪽 후보를 선택하면 같은 창 오른쪽의 큰 3D 뷰에서 모션이 자동 반복 재생됩니다.

- **Previous / Next** 또는 **왼쪽·오른쪽 방향키**: 실제 동작을 보면서 앞뒤 후보로 이동
- **Auto next**: 한 모션이 끝나면 다음 후보를 자동 재생
- **Space**: 재생·일시 정지
- **`,` / `.`**: 이전·다음 프레임
- **Keep in shortlist** 또는 **F**: 쓸 만한 모션을 후보 목록에 보관
- **Shortlist only**: 보관한 후보만 다시 모아서 검토
- **I / O**: 현재 프레임을 편집 구간 시작 / 끝으로 지정
- **선택 구간을 .anim으로 내보내기** 또는 **C**: 구간과 배속을 적용해 저장
- **재생 / 내보내기 배속**: 미리보기와 저장 결과에 동일하게 적용
- **Root motion / Weapon trail / Camera**: 루트 모션 및 표시 방식 변경

처음 여는 모션은 HKX를 아카이브에서 꺼내 Unity 클립으로 한 번 준비합니다. 준비된 클립은 `Assets/PrototypeGenerated/EldenRing/`에 캐시되므로 다음부터 즉시 재생됩니다. 16,512개를 전부 미리 임포트해 Unity 시작 시간을 늘리는 방식은 사용하지 않습니다. 원본 스켈레톤 모델과 자동 생성되는 마네킹 프리팹은 각각 다음 위치에 있습니다.

- `Assets/PrototypeReference/EldenRing/ER_Base_Male.fbx`
- `Assets/PrototypeGenerated/EldenRing/ER_Base_Male_Animated.prefab`

## 원본 모션 미리보기

라이브러리의 **Open detailed preview**를 누릅니다. 재생·일시 정지, 이전/다음 프레임, 타임라인 이동, 루트 모션 표시, 카메라 위치와 검 끝 궤적을 더 세밀하게 확인할 수 있습니다.

이 기준 모델로 원본 모션을 검토하고, 확정한 모션을 실제 게임 캐릭터에 적용합니다.

## 라이브러리에서 자르기·배속·내보내기

모션을 선택하고 오른쪽 미리보기 아래 **시작 프레임 / 끝 프레임 / 재생·내보내기 배속**을 조절합니다. 선택 구간을 반복 재생해 확인하고 **선택 구간을 .anim으로 내보내기**로 저장합니다. 다른 창이나 Move 생성은 필요하지 않습니다. 편집하면 Auto next가 해제됩니다. 후보별 편집값은 같은 창을 열어 둔 동안 기억합니다. Root motion 체크도 출력에 적용됩니다.

## 여러 구간 합치기와 기존 편집 .asset 사용

**CrossBlade > Motion Composer**에서 직접 편집하고 창 상단 **.anim 내보내기 · 자르기 / 배속 적용**으로 애니메이션만 저장할 수 있습니다. Move 생성은 선택 사항입니다.

Move도 함께 만들려면 **CrossBlade > Combat Move Graph > 애니메이션 → Move**를 사용할 수 있습니다.

이미 저장한 `.asset`은 Project 창에서 더블클릭하거나 **저장한 편집 (.asset)**에 넣습니다. **Move 만들기 · 전투 그래프에 추가**로 편집한 애니메이션과 Move를 함께 생성합니다.

각 구간에서 다음 값을 편집합니다.

- **시작 프레임 / 끝 프레임**: 사용할 원본 프레임 범위
- **저장할 재생 속도**: `2`는 두 배 속도, `0.5`는 절반 속도
- **Blend frames**: 앞 구간의 끝과 현재 구간의 시작을 겹쳐 보간할 출력 프레임 수
- **↑ / ↓**: 구간 순서 변경

**편집 저장**은 선택 사항입니다. 기존과 같은 `MotionSequenceAsset` 형식에 프레임 범위·속도를 보관하므로 나중에 다시 편집할 수 있습니다.

**Move 만들기 · 전투 그래프에 추가**를 누르면 모든 구간을 지정한 FPS로 샘플링한 `.anim`과 이 클립이 지정된 Move 프리팹을 저장합니다. 프리팹 저장 위치만 고르면 됩니다. 기존 파일은 덮어쓰지 않습니다. 창 상단 **.anim 내보내기 · 자르기 / 배속 적용**도 선택할 수 있습니다.

**Keep root motion**을 끄면 합성 결과의 캐릭터 루트 위치와 회전을 고정합니다. 켜면 원본에서 해석한 루트 트랜스폼 커브를 합성 결과에 포함합니다.

## 그래프로 연결하기

**CrossBlade > Combat Move Graph**에서 생성된 Move를 연결합니다.

- 가운데 마우스 드래그: 그래프 화면 이동
- 노드 드래그: 노드 위치 변경
- 다음 행동·방어·피격 출력 포트를 대상 노드 입력에 연결
- 연결선 선택 후 Delete: 연결 삭제

연결은 실제 Move의 전투 분기에 반영됩니다. 그래프 저장으로 노드 목록과 배치를 보관합니다. 이전 시퀀스 설계용 Motion Graph 메뉴는 제거했습니다.

## 추천 작업 순서

1. **CrossBlade > Elden Ring Motion Library**에서 무기나 그룹으로 검토 범위를 좁힙니다.
2. 큰 3D 뷰에서 재생되는 동작을 보며 Previous/Next로 후보를 넘깁니다.
3. 쓸 만한 동작은 **Keep in shortlist**로 표시합니다.
4. **Shortlist only**를 켜서 남긴 후보를 서로 비교합니다.
5. 라이브러리 미리보기 아래 시작·끝 프레임과 배속을 조절합니다.
6. 선택 구간을 반복 재생해 확인합니다.
7. **선택 구간을 .anim으로 내보내기**로 저장합니다.
8. 전투 행동이 필요하면 저장한 `.anim`을 Move로 만들고 그래프에서 전투 분기·이동·히트박스를 편집합니다.

## 검증 및 제한

- CrossBlade 프로젝트에서 16,512개 고유 모션 카탈로그를 읽는 것을 확인했습니다.
- 실제 기준 캐릭터와 준비된 모션으로 구간 자르기, 속도 변경, 블렌드, 순서를 바꾼 스크럽을 확인했습니다.
- 합성 결과를 독립 `.anim`으로 생성하고 길이, FPS와 트랜스폼 커브를 검사했습니다.
- 그래프 노드와 이름 있는 전이선의 저장·재로드를 확인했습니다.
- 기존에 준비되지 않았던 `a023_030200`을 CrossBlade에서 HKX부터 변환하여 1.3초/30 FPS Unity 클립으로 만들고 실제 손 본 움직임과 루트 커브를 확인했습니다.

모든 16,512개를 미리 변환한 상태는 아닙니다. 모든 항목을 검색할 수 있고 필요한 항목을 온디맨드로 준비하는 구조입니다. 일부 모션은 특정 장비, 보조 본, 효과나 게임 상태를 전제로 하므로 몸동작만으로 의미를 파악하기 어려울 수 있습니다.

검증 로그는 작업 공간의 `output/unity_integration/crossblade_motion_validation.log`와 `crossblade_motion_on_demand.log`에 있습니다.
