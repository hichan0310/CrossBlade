Drop Danjin animation FBXs here, preserving the validated Generic bone hierarchy and export axes. Open **CrossBlade > Animation Review** and select the imported FBX/take. Import settings are scoped to this folder. Review does not approve or assign automatically.

Re-exporting an FBX with the same name updates its unreviewed takes. Approved native snapshots remain unchanged. Keep each FBX's .meta when moving/renaming it inside Unity. See Documentation/AnimationReview.md.
